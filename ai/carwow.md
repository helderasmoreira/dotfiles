# Carwow workspace

Consider the repositories under this directory part of the "Carwow workspace".
They are managed by the same team and should share similar patterns, to some
extent.

## Delegation

- Non-trivial feature, refactor, or design work: run /architect before writing
  code. Skip it for small, obvious fixes.
- Rails implementation (app, lib, spec changes): dispatch carwow-rails-engineer,
  one subtask at a time. Don't write app code in the main conversation.
